ABOUT AGRIRAIN

Weather context for
everyday farm planning.

A college mini-project showing how an API forecast, a machine learning model, and a small local database can work together.

HOW IT WORKS

Three separate pieces

  1. Forecast service

    Open-Meteo provides daily minimum and maximum temperature, daily rainfall total, and hourly relative humidity forecast for the selected district coordinates.

  2. ML estimate

    A Random Forest classifier maps those four forecast values to a rain-likelihood label. If supported, its probability is displayed as an estimate.

  3. Prediction history

    SQLite stores the district, model result, available probability, forecast values, and save time so previous requests can be reviewed.

IMPORTANT LIMITATION

Not locally validated

The included WeatherAUS dataset contains Australian observations. A held-out test on that dataset does not demonstrate performance in Karnataka. The model is included for a learning demonstration only.

The web forecast comes from Open-Meteo; the classifier output is a separate experimental estimate. Neither should be treated as a guaranteed rainfall outcome or as a replacement for official local advisories.

Path to a stronger local model

Collect quality-controlled Karnataka station data with matching forecast-time inputs and rainfall labels, use time-based evaluation, and report performance for representative districts and seasons.
