{{ _('Three separate pieces') }}

  1. {{ _('Forecast service') }}

    {{ _('Open-Meteo provides daily minimum and maximum temperature, daily rainfall total, and hourly relative humidity forecast for the selected district coordinates.') }}

  2. {{ _('ML estimate') }}

    {{ _('A Random Forest classifier maps those four forecast values to a rain-likelihood label. If supported, its probability is displayed as an estimate.') }}

  3. {{ _('Prediction history') }}

    {{ _('SQLite stores the district, model result, available probability, forecast values, and save time so previous requests can be reviewed.') }}
